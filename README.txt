Project Description:
This is a Rails ToDo application with custom user accounts. Users can sign up, log in, create categories, create ToDo items, mark ToDos as priority, mark ToDos as completed, and delete their account. Each user only sees their own categories and ToDos.

Main Features:
- Custom user sign up and login
- User fields: first name, last name, username, email, password
- First name displays in the navbar when logged in
- Users can delete their account
- Deleting a user deletes their categories and ToDos
- Categories have name, description, and user_id
- ToDos have title, priority, completed, category_id, and user_id
- Category has many ToDos
- ToDo belongs to one Category
- Completed ToDos page
- Bootstrap design
- Bootstrap icons
- Custom CSS

Packages/Libraries Used:
- Ruby on Rails
- SQLite3
- bcrypt
- Bootstrap CDN
- Bootstrap Icons CDN
